| 3\. Fundamentación Proyecto APT |
| :---- |
| A continuación, se presentan distintos campos que debes completar con la información solicitada. Esta sección busca que describas en detalle tu proyecto y justifiques su relevancia y pertinencia.   |

| Relevancia del proyecto APT | El proyecto "SGP-Minero" aborda una falla crítica en la interoperabilidad y seguridad de la información logística dentro del sector minero corporativo. Actualmente, el área de logística de una empresa minera se enfrenta al procesamiento manual de solicitudes de pasajes mediante planillas Excel con formatos variables (columnas dinámicas), lo que genera manipulación intensiva y alta susceptibilidad a errores humanos. La falta de validación automatizada de identidad (RUT y Nombre) provoca la compra de pasajes inválidos, traduciéndose en pérdidas económicas directas. Además, el manejo de Información de Identificación Personal (PII) en archivos sueltos y sin cifrar representa una vulnerabilidad crítica que contraviene la Ley N° 19.628 sobre Protección de la Vida Privada en Chile. Este proyecto es altamente relevante para el campo laboral informático, ya que aborda un problema real B2B mediante la modernización, estandarización y securización de la ingesta de datos corporativos.  |
| :---- | :---- |
| Descripción del Proyecto APT | Se desarrollará "SGP-Minero" (Sistema de Gestión de Pasajes), una plataforma web segura que estandariza la ingesta de planillas Excel mediante una interfaz de mapeo dinámico (Mapper UI) y un motor algorítmico de validación de identidad. El sistema permitirá a usuarios operativos ("Cargadores") subir archivos, emparejar columnas obligatorias y delegar al backend la validación matemática del RUT y la coincidencia contra una base maestra. Los datos válidos serán almacenados en una arquitectura de base de datos híbrida (PostgreSQL), donde los campos sensibles (PII) serán cifrados simétricamente (AES) antes de persistir en una columna dinámica de tipo `JSONB`.  |
| Pertinencia del proyecto con el perfil de egreso | SGP-Minero integra directamente las competencias de construcción de software web, diseño de bases de datos y ciberseguridad. El uso de **Python (Django)** y **pandas** permite resolver el problema de extracción y procesamiento masivo de datos. **React (Vite)** proporciona una experiencia B2B fluida (SPA) para el mapeo visual de columnas. El modelo relacional en **PostgreSQL** junto con su tipo de dato nativo **JSONB** responde a la necesidad de almacenar datos variables sin romper el esquema. Finalmente, la orquestación en contenedores **Docker** certifica la capacidad de administrar entornos y portabilidad.  |
| Relación con los intereses profesionales | El proyecto permite desempeñarse integralmente como Desarrollador Full-Stack, aplicando prácticas de aseguramiento de calidad (QA) y gestión ágil mediante Scrum. Responde al interés del equipo por el desarrollo de arquitecturas modernas y seguras en la nube (DevSecOps), preparando al equipo para enfrentar los altos estándares técnicos de la industria del software.  |
| Factibilidad de desarrollo del Proyecto APT | El proyecto es completamente factible para desarrollarse en el plazo estricto de 18 semanas. Se mitigará el riesgo de presupuesto utilizando herramientas Open Source y Cloud de capa gratuita (Vercel, Render, Neon, Docker). La complejidad se mantiene abordable al declarar restricciones funcionales estrictas, prohibiendo expresamente las integraciones con pasarelas de pago, aplicaciones móviles nativas y conexiones automatizadas con sistemas ERP externos.  |
